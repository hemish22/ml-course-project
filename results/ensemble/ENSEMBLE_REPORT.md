# Review 3 (PBL-3): Ensemble Learning for Video Moment Retrieval

Generated by `scripts/run_ensemble.py` from `analysis/ensemble.py`. All numbers are
held-out results: each video is predicted by models that never saw it.

## 1. Problem identification and dataset selection

Task: for each (query, second of video) decide whether that second belongs to the
answer interval (`rel_binary`). The dataset is the Review 1 feature table
`results/ml/dataset.csv.gz`: 28,900 rows, 9 NASA videos,
86 queries, 31 engineered features from frozen CLIP / Whisper /
MiniLM similarities, and 2,385 positive rows
(8.3%). Ensembles suit this task: the features interact
non-linearly (distance to peak × score level × speech presence), and Review 1 showed
that a single model's errors vary strongly between videos, which averaging can reduce.

Protocol: leave-one-video-out (9 folds), grouped 3-fold inner CV over training
videos for CART depth, stacking, BMA weights, output smoothing and the F1 threshold.
No class re-weighting is used, so every learner outputs calibrated-style probabilities;
the class imbalance is handled by the training-selected F1 threshold.

## 2. Implemented ensemble approaches

| Method | Type | Configuration |
|---|---|---|
| CART tree | single tree (reference) | Gini; depth from [4, 6, 8, 12] by inner-CV PR-AUC (chosen: {4: 8, 6: 1}); min leaf 20 |
| Bagging | parallel, bootstrap | 300 unpruned CART trees, bootstrap samples |
| Random forest | parallel, bootstrap + feature subsampling | 300 trees, √p features per split, min leaf 5 |
| Extra trees | parallel, randomized splits | 300 trees, random thresholds, √p features |
| AdaBoost | sequential boosting (SAMME) | 300 depth-2 trees, learning rate 0.5 |
| Hist. gradient boosting | sequential boosting (log-loss gradient) | {'max_iter': 300, 'learning_rate': 0.05, 'max_leaf_nodes': 31, 'l2_regularization': 1.0} |
| Soft voting | heterogeneous averaging | mean probability of Logistic regression (base), Random forest, Hist. gradient boosting |
| Stacking | heterogeneous, learned combiner | logistic meta-learner on out-of-fold log-odds of 8 base learners |
| Bayesian model averaging | heterogeneous, probabilistic | pseudo-BMA+ weights from out-of-fold log predictive density, Bayesian bootstrap over queries (1000 draws) |

Mean BMA weights: Logistic regression (base) 0.83, Random forest 0.13, Extra trees 0.04.
Most common smoothing width per method: AdaBoost 9 s, Bagging 9 s, Bayesian model averaging 3 s, CART tree 15 s, Extra trees 9 s, Hist. gradient boosting 1 s, Random forest 9 s, Soft voting 1 s, Stacking 3 s.

## 4. Result interpretation

* Best ensemble by mean F1: **Bayesian model averaging** (F1 0.771, PR-AUC 0.853,
  Hit@1 0.938, temporal IoU 0.637).
* Single CART tree: F1 0.761, PR-AUC 0.796. Bagging/forests
  raise PR-AUC to 0.839 (random forest) by averaging away tree variance.
* Figures in `results/ensemble/figures/`: comparison (01), ensemble size (02), CART depth (03),
  CART tree (04), diversity (05), combiner weights (06), feature importance (07), PR curves (08),
  paired differences (09), per-video F1 (10), cost vs quality (11), confusion (12), example timelines (13).
